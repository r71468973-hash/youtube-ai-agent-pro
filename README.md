# youtube-ai-agent-pro
AI-powered YouTube Automation Agent that creates video scripts, generates AI voiceovers, produces videos and thumbnails, and uploads videos to YouTube after user approval.

## AI Video Studio

A self-hosted dashboard that turns a text story into a narrated, captioned video and uploads it to YouTube **only after you approve it**.

| Feature | How it works |
|---|---|
| Story to video | Story is split into scenes (Anthropic if a key is set, otherwise sentence splitting), then rendered with ffmpeg |
| Hindi and English voiceover | ElevenLabs, OpenAI or Google Cloud TTS (first key found, or your choice) |
| Shorts and long videos | 1080x1920 (9:16) or 1920x1080 (16:9) |
| Subtitles and music | Burned-in captions (Devanagari supported); built-in ambient beds or your own uploads, auto-ducked under the voice |
| YouTube | Google OAuth 2.0 (PKCE, offline access); resumable upload |
| Approval gate | Videos stop at **Awaiting your approval**. Upload needs an explicit approve action with a confirmation box; a failed upload consumes the approval |
| Cloud storage | Any S3-compatible bucket (Cloudflare R2, AWS S3, Backblaze B2, Supabase, MinIO) |
| API keys | Encrypted at rest (AES-256-GCM), write-only in the UI, never returned by the API |
| Dashboard | Mobile-first, bottom tab bar on phones, light and dark mode |

No npm dependencies. Requires Node 20+ and `ffmpeg`/`ffprobe`.

### Run

```bash
cp .env.example .env        # optional; set at least ADMIN_PASSWORD
export $(grep -v '^#' .env | xargs)
npm start                   # http://localhost:3000
npm test                    # end-to-end smoke test (renders real videos)
```

If `ADMIN_PASSWORD` is not set, one is generated and saved to `data/.admin_password`.

### Docker

```bash
docker build -t ai-video-studio .
docker run -p 3000:3000 -v aivideo-data:/app/data -e ADMIN_PASSWORD=change-me -e APP_SECRET=$(openssl rand -hex 32) ai-video-studio
```

This needs a long-running server with ffmpeg and a persistent disk (a VPS, Fly.io, Railway, Render). It will **not** work on serverless hosts such as Vercel or Netlify.

### Connect YouTube

1. In Google Cloud Console enable **YouTube Data API v3** and create an OAuth client (type *Web application*).
2. Add the redirect URI shown in **Settings > YouTube** (`BASE_URL` + `/auth/google/callback`). Set `BASE_URL` to your public HTTPS address in production.
3. Paste the client ID and secret in **Settings > API keys**, then press **Connect YouTube**.

Note: uploads from unverified Google API projects are forced to *private* by YouTube until the project passes an API audit. Uploads are labelled as AI-generated by default (toggle in Settings).

### Cloud storage

In **Settings > Cloud storage** enter endpoint, bucket and region, and save the access key ID and secret under API keys. Each finished video is copied to the bucket; downloads fall back to a time-limited signed URL if the local file is gone.

### Security notes

- Single-owner login, signed HttpOnly SameSite cookies, CSRF token on every write, login throttling, strict CSP.
- Set a stable `APP_SECRET` (16+ chars) in production. Changing it makes stored keys unreadable.
- Run behind HTTPS. Never commit `data/` or `.env` (both are git-ignored).
